# ROSH Luxury Ecommerce

ROSH is a polished, responsive luxury fashion ecommerce prototype with a large generated catalog for men's, women's, and children's fashion.

## Run Locally

```bash
npm start
```

The server prints the local URL, usually `http://localhost:4173`.

## Included

- Responsive homepage, collection pages, product detail pages, wishlist, cart, checkout, confirmation, account dashboard, lookbook, about, contact, FAQ/returns, privacy, and terms.
- Advanced catalog browsing with category tabs, search, price filtering, sorting, quick view, wishlist, cart animations, product badges, and load-more pagination.
- Local secure server with CSP/security headers, path traversal protection, JSON body size limits, rate-limited API routes, validation, and sanitized form inputs.
- No committed secrets. Use `.env.example` as a template and keep real values in `.env`.

This is a production-style frontend and secure local API simulation. Connect real authentication, inventory, tax, shipping, and payment providers before accepting real orders.
